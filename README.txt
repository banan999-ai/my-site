# Педагогический навигатор

Загрузка на GitHub Pages:
1. Загрузите ВСЕ файлы и папки из этого архива в корень репозитория.
2. В Settings → Pages выберите Deploy from a branch.
3. Branch: main, Folder: / (root).
4. Сохраните и дождитесь публикации.

Структура:
- index.html — главная
- orlyata/index.html — отдельная страница Орлят России
- pervye/index.html — отдельная страница Движения Первых
- assets/ — стили и JavaScript

Кнопка «Задать вопрос» ведёт на указанную Google Форму.
